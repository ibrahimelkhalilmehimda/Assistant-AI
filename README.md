🤖 Agentic RAG AI Chatbot
Un assistant conversationnel intelligent propulsé par une architecture RAG agentique, LangGraph et ChromaDB, doté d'une interface web moderne.

📌 À propos du projet
Ce projet implémente un chatbot d'intelligence artificielle hautement contextuel et autonome. En combinant la génération augmentée par récupération (RAG) avec un système de contrôle par agents (via LangGraph), l'application ne se contente pas de chercher des documents similaires : elle évalue la pertinence des sources, planifie ses recherches et formule des réponses précises.

La persistance des vecteurs est assurée par ChromaDB, tandis que l'interaction utilisateur s'appuie sur une interface web épurée et réactive en HTML, CSS et JavaScript.

⚙️ Fonctionnalités principales
Architecture RAG Agentique : Utilisation de graphes d'états pour orchestrer le raisonnement, la recherche documentaire et la synthèse de la réponse.

Orchestration avec LangGraph : Gestion fluide des flux conversationnels complexes et des boucles de rétroaction de l'agent.

Base de données vectorielle ChromaDB : Stockage et recherche ultra-rapide des embeddings pour un accès instantané à la base de connaissances.

Interface Web Moderne : Développée en HTML, CSS et JavaScript pour une expérience utilisateur fluide et intuitive.
